Hier liegen ausschließlich **Kopien offiziell exportierter** .streamDeckProfile-Dateien.
Es werden keine internen Stream-Deck-Profile erzeugt oder umgeschrieben.
Exportdateien mit dem Assistenten `Profile-einbinden.cmd` in ein gebautes Paket einbinden.
Für eigene Quellbuilds: `node scripts/profiles.mjs dist/de.heki.autoprofile.sdPlugin`.
Danach optional die eingebundenen Dateien und catalog.json zurück in diesen Ordner kopieren.
Exportdateien können vertrauliche Aktionssettings enthalten: nicht öffentlich verteilen.
