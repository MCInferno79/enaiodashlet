# Optionale Exportprofile

PageDeck-Webseiten-Tasten benötigen keine mitgelieferten Profile. Das eigene Profil wird direkt in Stream Deck angelegt und bearbeitet; Zuordnungen und Schritte werden in Edge konfiguriert.

Dieser Ordner und `Profile-Paket-erstellen.html` dienen ausschließlich dem weiterhin optionalen SDK-Profilwechsel. Elgato erlaubt dabei nur im Manifest registrierte Exportprofile, keine frei auflistbaren Benutzerprofile. Echte `.streamDeckProfile`-Dateien werden ausschließlich lokal ausgewählt und bytegleich übernommen. Keine persönlichen Exporte in dieses öffentliche Repository hochladen.
