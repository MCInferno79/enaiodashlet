Hier liegen ausschließlich **Kopien offiziell exportierter** .streamDeckProfile-Dateien.
Es werden keine internen Stream-Deck-Profile erzeugt oder umgeschrieben.
Endanwender verwenden die lokale Seite Profile-Paket-erstellen.html aus dem Release-ZIP.
Sie benötigt nur Edge und erzeugt ein neues .streamDeckPlugin-Installationspaket.
Für Entwickler auf dem Buildrechner bleibt scripts/profiles.mjs optional verfügbar.
Exportdateien können vertrauliche Aktionssettings enthalten: nicht öffentlich verteilen.
