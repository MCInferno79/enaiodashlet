# PageDeck 2.0: Abnahme auf Windows und Stream Deck XL

Stand 14.10.2026. Die folgenden Hardwareprüfungen sind offen. Automatisierte Tests mit simuliertem Host ersetzen sie nicht.

| Prüfung | Erwartung | Status |
|---|---|---|
| Offizieller Doppelklick-Installer | PageDeck mit beiden Aktionen installiert; keine separate Node-Installation | offen |
| Update von 1.x | Steueraktion/Kopplung nutzbar; eigene Benutzerprofile erhalten; alter Profilwechsel zunächst aus | offen |
| Edge-Erweiterung laden | Neue Webseiten-Oberfläche; keine vorgegebenen Fachanwendungen | offen |
| Koppeln | Code sichtbar und innerhalb zweier Minuten nutzbar | offen |
| Nummern ändern | SDK-Settings speichern die gewählte Nummer; Neuöffnen zeigt sie wieder | offen |
| Webseite A/B wechseln | Dieselbe Deck-Taste zeigt passende Beschriftung und führt passenden Ablauf aus | offen |
| Text + Klick | Auf geeigneter Testseite erwartete Werte und genau ein Klick | offen |
| Seiten-Tastenkürzel | In der gewählten Webanwendung unterstützt oder Einschränkung sichtbar | offen |
| Scrollen / Öffnen | Gewünschte Richtung bzw. Zieladresse im bisherigen Tab | offen |
| Neuer Ablauf | Ohne neues Pluginpaket speicherbar und ausführbar | offen |
| Fokusverlust / unbekannte Seite | Keine Eingabe in Hintergrundseite | offen |
| Fehlende Website-Freigabe | Keine DOM-Ausführung, verständliche Rückmeldung | offen |
| Edge-/Plugin-Pause | Keine Seitenaktionen; getrennt fortsetzbar | offen |
| Stream Deck / Edge neu starten | Verbindung und Tasten nach Wiederverbindung korrekt | offen |
| Gemischtes eigenes Profil | Normale Hotkeys und Drittplugin-Aktionen neben PageDeck weiter nutzbar | offen |
| Import/Export | Webseiten und Schritte erhalten; keine Kopplungstokens exportiert | offen |
| Unternehmensrichtlinien | Erweiterung, Website-Zugriff und lokale Verbindung freigegeben | offen |
